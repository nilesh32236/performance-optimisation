WHAT IT DOES

Stores a finished copy of each page so WordPress does not rebuild it for every visitor. Bypasses PHP and MySQL execution entirely for cached requests, serving static HTML and pre-compressed responses directly.

WHAT IT COSTS YOU
No known downside. Pages are regenerated automatically when content changes.

Disk space is capped at 500 MB with FIFO garbage collection enabled.
