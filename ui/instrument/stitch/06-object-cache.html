Memory Compression

redis.compression.algorithm
WHAT IT DOES

Compresses values before they are written to Redis so more of the cache fits in memory.

Decompression is executed lazily on payload retrieval inside the worker thread prior to deserialization into runtime memory.

WHAT IT COSTS YOU

Compression trades CPU for memory. ZSTD is the best balance and is what we recommend; LZF is faster but compresses less; LZ4 is fastest and compresses least.

Server capabilities: LZF, LZ4 and ZSTD supported.
