Orphaned Post Meta

wp_postmeta table cleanup

WHAT IT DOES

Deletes metadata entries in wp_postmeta that point to post IDs that no longer exist in the database.

Leftover meta commonly accumulates when deleting custom post types, WooCommerce orders, or page builder revisions without cascading deletes.

WHAT IT COSTS YOU

These rows are not referenced by any post. Deleting them is usually safe, but a plugin that stores data outside the normal WordPress tables can lose its settings.

Recommendation: Run an export backup before purging if you run custom ERP syncs or legacy membership plugins.
