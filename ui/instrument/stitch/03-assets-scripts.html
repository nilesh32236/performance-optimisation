Remove Unused CSS

Core Stylesheet Purge Engine

WHAT IT DOES

Scans each page, works out which CSS rules are actually used, and strips the rest.

Unused rules are filtered out of all enqueued files and inline style tags before markup delivery, significantly reducing total stylesheet payload.

warning WHAT IT COSTS YOU

Aggressive. A rule that only appears after a click can be stripped, which breaks menus and popups.

The safelist below is the guard — add any selector that must survive.
