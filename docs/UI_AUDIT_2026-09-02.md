## Additional Observations (not filed as separate issues — keep as backlog)
- `.wppo-code-block` Nginx rules uses `white-space:pre` with `overflow-x:auto` but no `overflow-wrap`; long one-liner configs require horizontal scroll — acceptable for code, but add `max-height:320px` + sticky header for long blocks.
- `FeatureCard` hover `transform:translateY(-1px)` disabled via `@media (hover:none)` — correct, but still triggers on hybrid devices (iPad with mouse) — keep.
- `ConfirmDialog` `animation: wppo-dialog-in 0.2s cubic-bezier(0.34,1.56,0.64,1)` slightly bouncy — intentional delight, respects `prefers-reduced-motion`.
- Empty states: Web Vitals, Suggestions, PageSpeed panels show skeleton not — consider adding `wppo-loading-placeholder` with `role="status"` while `apiCall` pending (currently handled per-panel but inconsistent).
- File input `.wppo-input` on `[type="file"]` inherits `padding:9px 12px` with native button unstyled — minor visual inconsistency in Tools Import; consider `::file-selector-button` styling.
