You can open Performance Optimisation in a browser tab, with no server and no install step, using a WordPress Playground blueprint shipped with the plugin. It is the fastest way to look around before deciding whether to install anything on a real site.

Open the demo

The blueprint lives in the plugin repository at .wordpress-org/playground/blueprint.json. Point Playground at it:

https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fnilesh32236%2Fperformance-optimisation%2Fmaster%2F.wordpress-org%2Fplayground%2Fblueprint.json

It boots WordPress 7.1 on PHP 8.2, installs and activates Performance Optimisation 2.4.0, logs you in as admin / password, and opens the Performance Optimisation Dashboard directly.

Why the WordPress version is pinned

The blueprint requests WordPress 7.1 rather than latest. That matches the Tested up to: 7.1 this plugin declares, so the demo and the claim say the same thing. latest would make the demo unreproducible: what a visitor sees today would drift from what they see next month, and away from what the plugin actually claims to support.

Running the blueprint yourself

The blueprint is plain JSON and validates against the published schema at https://playground.wordpress.net/blueprint-schema.json. To fork it:

git clone https://github.com/nilesh32236/performance-optimisation
cd performance-optimisation
python3 -c "import json; print(json.load(open('.wordpress-org/playground/blueprint.json')))"

To try a different WordPress or PHP version, change preferredVersions.wp and preferredVersions.php. A result in Playground is a useful smoke test of the admin surface, not a compatibility certification — see the Compatibility page for what each label there actually means, and the claim register in the repository for the evidence behind each version number.

What the demo deliberately does not do

  • It sends nothing to an analytics service, tracking pixel, or telemetry endpoint. The only outbound requests are to GitHub Releases and WordPress.org.
  • It contains no affiliate link, referral code, or rating prompt.
  • It is disposable. The admin / password credentials are public and are not a secret.
