What it does

File Optimization can minify HTML, CSS, and JavaScript, combine eligible stylesheets, remove selected WordPress bloat, and host Google Fonts locally. Each transform writes a generated asset only after containment and safety checks.

When to use it

Use minification for a measured transfer-size or parse cost. Test one asset family at a time. Use CSS combining only when a request-count reduction helps the site and HTTP/2 or HTTP/3 is not harmed.

Safe default

External and inline minification, combining, and local font hosting start disabled. Elementor-safe mode stays on by default, so Combine CSS steps aside on builder-built pages. The plugin keeps exclusions and a complete stylesheet fallback for eligible paths.

How to enable it

  1. Open File Optimization → Assets.
  2. Enable HTML, CSS, or JavaScript minification separately.
  3. Clear one representative page cache and inspect rendered HTML and the Network panel.
  4. Test navigation, forms, popups, and builder layouts before saving more changes.
  5. Add exact handles or URLs to the matching exclusion list if a file breaks.

What changes

Eligible source files are read, transformed, stored with a stable version, and served through a rewritten URL. Combining merges eligible stylesheets. Local font hosting changes the font source. Already-minified, unsafe, excluded, or builder-critical assets stay untouched.

Compatibility considerations

  • Builder-generated CSS can arrive after a page render. Keep Elementor-safe mode and the CSS safelist active.
  • JavaScript can depend on execution order. Exclude consent, payment, menu, and critical builder scripts.
  • Some hosts and CDNs cache by URL only. A generated asset URL must change whenever its content changes.
  • Combining is not automatically better on HTTP/2 or HTTP/3.

How to verify

wp wppo cache clear --page=/sample-page/
wp wppo cache status

Compare the HTML source, CSS cascade, JavaScript console, responsive layout, and first interaction. A smaller file that breaks a menu is not an optimization.

How to undo or disable

Disable the narrowest transform, save, clear the page cache, and reload. Keep the exact failing handle in the exclusion list. Use the preset restore point if a bundle changed several settings.

Troubleshooting

  • CSS is missing: disable Combine CSS, keep the handle excluded, and clear derived CSS.
  • JavaScript fails: disable minification for that family, inspect the console, and exclude the handle.
  • Builder output breaks: keep Elementor-safe mode on and test the sandbox preview before promoting changes.
  • Fonts change: disable local font hosting and clear the page and edge cache.

FAQ

Is combining CSS safe for every site?

No. It can change cascade order and request behavior. Test the exact theme and builder.

Why was my file excluded?

The file may be already minified, unsafe, builder-critical, or listed in an exclusion. Check the current exclusion list and settings reference.

Can I undo a preset?

Yes. The Dashboard preset card creates a restore point and exposes an Undo action.
