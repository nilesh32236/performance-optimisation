Getting started

What should I enable first?

Start with Page Cache and keep the existing WooCommerce safe mode on. Record a baseline, then add one asset or image option at a time. The installation guide gives the sequence.

Which preset should I choose?

Safe is the beginner baseline. Balanced is the recommended starting point after a baseline. Aggressive requires testing and should stay off until the site and critical interactions are stable.

Features

What does Page Cache do?

It stores eligible rendered HTML and serves it before WordPress boots on a hit. See Page Cache.

What does Image Optimization do?

It combines lazy loading, LCP protection, WebP/AVIF conversion, and delivery rules. See Images, WebP, and AVIF.

How do I improve Core Web Vitals?

Measure first, then map LCP, INP, or CLS to the matching feature. The Core Web Vitals guide explains the path.

What is Redis Object Cache?

It reduces repeated database reads when a request reaches PHP. See Redis Object Cache.

Safety and compatibility

Does the plugin cache every page?

No. Admin, REST, feeds, errors, private requests, unsafe query strings, and dynamic WooCommerce routes bypass shared caching.

Can I run it beside another cache plugin?

Only with one page-cache owner. LiteSpeed has explicit modes; disable the competing page-cache module. Review the compatibility matrix.

Is native lazy loading enabled by default?

Yes. The native browser path is preferred, and the legacy JavaScript observer is opt-in. LCP guardrails protect above-the-fold content.

What should I do if CSS or JavaScript breaks?

Disable the narrowest transform, save, clear the page cache, and keep the exact handle excluded. Start with the troubleshooting page.

Credentials and data

Where are credentials stored?

Use server-side constants, environment paths, or the supported connector surface. Exports redact secret-shaped values. Never paste passwords, API keys, authorization headers, or cookies into documentation or bug reports.

Does RUM store form values?

No. The beacon stores bounded performance metrics, not names, emails, form values, user IDs, or cookies with samples.

Reference and help

What does wp wppo verify check?

It reports runtime, filesystem, cache, Redis, LiteSpeed, settings, cron, and uninstall-hygiene findings. Read the full result before treating a warning as a release blocker.

How do I report a problem?

Open an issue with versions, server software, reproduction URL, the exact setting, and a redacted wp wppo system-info output.
