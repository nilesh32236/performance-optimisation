Start with a user task

  • Improve Core Web Vitals — map LCP, INP, and CLS to the existing cache, image, preload, CSS, JavaScript, and monitoring controls.
  • Configure a CDN — choose an edge owner, keep purge credentials server-side, and verify the origin and edge separately.
  • Check compatibility — separate verified, supported, best-effort, and known-limitation boundaries.

Core delivery features

  • Page cache — static HTML generation, serving, invalidation, capacity limits, role variants, and WooCommerce-safe exclusions.
  • Redis object cache — standalone, Sentinel, and Cluster connections, TLS, compression, a circuit breaker, and a managed drop-in.
  • Minification and combining — HTML, CSS, JavaScript, inline payloads, CSS combining, and explicit exclusions.
  • Defer and delay JavaScript — interaction, idle, viewport, priority, and opt-in third-party strategies with a safe preset.
  • Used and critical CSS — per-template critical CSS, per-URL used CSS, staged preview, promotion, health checks, and rollback.
  • Images, WebP, and AVIF — native or opt-in observer lazy loading, LCP guardrails, next-generation conversion, and server delivery rules.
  • Database cleanup — nine explicit cleanup types, dry-run previews, scheduling, and autoloaded-options remediation.
  • Preload and speculation — cache warm-up, sitemap discovery, resource hints, LCP/font discovery, and conservative speculation rules.
  • Monitoring: PageSpeed and RUM — lab scans, first-party field Web Vitals, read-only suggestions, and anomaly notices.

Trust and recovery

Performance Optimisation is free and open source. Start with Safe, test the site, review the measurement, and enable advanced options only when needed. If a change breaks the site, disable the narrow feature, clear the affected page, and use the support and safe recovery guide.

Rollout discipline

Use the Dashboard preset and sandbox controls to preview a bounded change before promoting it. Keep WooCommerce safe mode enabled while testing cart, checkout, account, Store API, and faceted URLs. Keep advanced defer/delay and asset-removal options off until a staging test proves the first interaction and layout remain correct.
