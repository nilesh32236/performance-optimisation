What it does

Image Optimization reduces initial image work through lazy loading, LCP protection, WebP/AVIF conversion, and server delivery rules. Original Media Library files stay available as the source of truth.

When to use it

Use it when images dominate page weight, the LCP element is an image, or lower-resolution devices receive oversized files. Start with the measured hero image and one representative content page.

Safe default

Native lazy loading and LCP guardrails are enabled. The legacy observer, automatic LCP preload, and aggressive background-image policies are opt-in. AVIF-first selection and smart quality are enabled where the runtime supports them.

How to enable it

  1. Open Image Optimization.
  2. Keep native lazy loading on and exclude the logo, hero, and above-the-fold images from lazy loading.
  3. Review LCP Preload and enable automatic preload only after a real or PageSpeed candidate is available.
  4. Choose WebP, AVIF, or both and review the quality and maximum edge settings.
  5. Save, run a conversion, and check the browser's selected source.

What changes

The plugin adds loading hints, protects the measured LCP image, creates next-generation siblings, and may rewrite delivery to a supported format. A failed or pending conversion leaves the original upload available.

Compatibility considerations

  • Server rules must preserve the original fallback and correct MIME/Vary behavior.
  • Apache and LiteSpeed can apply marked .htaccess rules. Nginx needs server configuration. Restart OpenLiteSpeed after rule edits.
  • Builder widgets can add late images. Review Elementor and Divi exclusions before enabling background-image lazy loading.
  • CDN caching must vary on the delivered format or keep the original fallback reachable.

How to verify

wp wppo image status
wp wppo image convert

In the browser, inspect the image source, intrinsic dimensions, alt text, loading attribute, and fetchpriority. Test the hero before content images. Confirm WebP or AVIF only after the server returns a valid fallback for unsupported clients.

How to undo or disable

Turn off the specific image option, save, clear the affected page cache, and remove the setting from the preset. Keep the original upload. Disable automatic LCP preload first if the wrong image is prioritized.

Troubleshooting

  • Images disappear: remove the image from lazy-loading exclusions and clear the page cache.
  • Wrong format is served: check generated files, MIME rules, and the CDN's format policy.
  • LCP gets slower: disable automatic preload, verify the hero loads eagerly, and inspect TTFB.
  • Builder layout changes: exclude the builder section and re-test after the builder regenerates assets.

FAQ

Does conversion delete the original image?

No. The original remains the source of truth.

Should every image be lazy-loaded?

No. The hero and other above-the-fold images can make LCP worse when delayed.

Why is AVIF not served?

Check conversion status, the image extension support, the server's MIME/Vary rules, and the CDN cache.
