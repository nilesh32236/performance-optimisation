## 4. Proposed Command Hierarchy ( `wp wppo <subcommand> <action>` vs Alias `wppo` )

**Recommendation:** Keep `wp wppo` (registered `WP_CLI::add_command('wppo', 'PerformanceOptimise\Inc\WPPO_CLI_Command')` at `includes/class-main.php:472-474` class-as-collection of subcommands `WP-CLI-RESEARCH.md §1` `WP_CLI::add_command($name, $callable)` pattern, handbook "Include in a plugin or theme" `if(defined('WP_CLI')&&WP_CLI)`). Do **not** add top-level alias `wppo` (`wp wppo` already 4-char short, collision risk low like `rocket` `ECOSYSTEM-RESEARCH.md §4.1.1`). LiteSpeed multi-root `litespeed-purge`/`litespeed-option`/`litespeed-image` (8 families) is warranted only ≥10 `wppo` families — WPPO has 7, `W-11` proves 15 would bloat `WPPO_CLI_Command:973` to 2k lines.

**Hierarchy (retain 7, enhance flags — no new subcommands per `W-11`):**

```
wp wppo cache        → clear | preload | status          (@subcommand cache :70)
wp wppo database     → cleanup | optimize | counts       (@subcommand database :169)
wp wppo image        → convert | status                 (@subcommand image :316)
wp wppo settings     → get | update | export | import   (@subcommand settings :567)
wp wppo object-cache → status | ping | enable | disable | flush  (@subcommand object-cache :796 dash→underscore method object_cache)
wp wppo pagespeed    → scan | results                   (@subcommand pagespeed :897)
wp wppo system-info  → [group]                            (@subcommand system-info :952)
```

Future non-alias: if ≥10 families proven, split `wp wppo cron …` / `wp wppo crawler …` like LSCWP — not before.

**Global flags:** `wp --url=<site> wppo …` (WP-CLI global `--url` "In multisite, how target site is specified" `WP-CLI-RESEARCH.md §1`), `[--network]` opt-in, `[--yes]` (`--confirm` alias Rocket) + `[--dry-run]` + `[--format]`/`[--fields]`/`[--field]`/`[--batch-size]` per handbook DB-migration recipe `max(1,(int)…)` + `WP_CLI\Utils\get_flag_value` (`ECOSYSTEM-RESEARCH.md §4.1.7`).
