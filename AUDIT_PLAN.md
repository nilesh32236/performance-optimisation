## P0 — Critical & Breaking Issues

### AUDIT-0001 `[COMPLETED]` — Baseline verification of REST security posture
- **Status:** Reviewed all 21 REST endpoints in `class-rest.php`.
- **Findings:** Every route uses `permission_callback` → `permission_callback()` which enforces
  `current_user_can( 'manage_options' )` + `wp_verify_nonce( 'wp_rest' )`. All dynamic values run
  through `sanitize_text_field`/`absint`/`esc_url_raw`/`sanitize_settings_recursively()`. Redis
  password is never stored (boolean `password_set` flag instead). PageSpeed API key is stripped
  from REST responses. Telemetry/PageSpeed endpoints validate URL host (SSRF guard) and scheme.
- **Verdict:** No P0 security defects found. Locked-in; re-verify at Phase 4.

## P2 — Performance & Architecture Optimizations

### AUDIT-0006 `[COMPLETED]` — `is_url_excluded()` re-resolves `home_url()` per rule per URL
- **Files:** `includes/class-util.php`.
- **Fix:** Resolve the home base once per request via a blog-id-keyed static cache, only
  re-resolving when a `home_url` filter is active (which may legitimately change the value).
  Root-relative rules are then joined against the cached base. Preserves multisite safety.
- **Verification:** `phpunit` OK (174 tests), `phpcs` clean.

### AUDIT-0007 `[COMPLETED]` — REST + DB query review
- **Status:** Reviewed `Database_Cleanup`, `Log`, `Telemetry`, `Cron` for N+1/unbounded queries.
- **Findings:** Batched deletes (LIMIT 1000 loops), `COUNT(*)` SQL, transient/salted-cache keys,
  `posts_per_page=200` preload batches, `Util::transient_key()` blog-id namespacing. No N+1 in
  page-load paths.
- **Verdict:** No P2 defects in this area. Locked-in.

### AUDIT-0008 `[COMPLETED]` — Asset loading audit
- **Status:** `admin_enqueue_scripts` hooks are page-scoped to the plugin admin screen; `src/index.js`
  + `src/lazyload.js` are the only build entries; CDN rewrite / minify compiled once; IntersectionObserver
  disconnect + MutationObserver cleanup present in `src/lazyload.js`.
- **Verdict:** No P2 defects. Locked-in.
